ARRAYS, FOR Y FOR...OF EN JAVASCRIPT

Array: Lista ordenada de datos
const lista = ["dato1", "dato2"];

For tradicional: Recorre por índice
for (let i = 0; i < lista.length; i++) {
  console.log(lista[i]);
}

For...of: Recorre valores directo
for (const item of lista) {
  console.log(item);
}

Uso comunitario: Organizar propuestas, mensajes y fuentes para revisión transparente.
