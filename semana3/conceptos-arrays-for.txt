7. ¿Qué hace for...of?

Respuesta: El bucle for...of es la forma moderna, limpia y "fácil"
 de recorrer arrays en JavaScript.

8. ¿Qué diferencia inicial encuentras entre for y for...of?

Respuesta:for tradicional: Se centra en el índice (la posición 0, 1, 2...). Para obtener el dato, tienes que pedirlo manualmente usando array[i].

for...of: Se centra directamente en el valor (el dato real). JavaScript extrae el elemento y te lo entrega listo para usar en una variable.

Respuesta: es un comando personalizado para ejecutar array-basico

10. ¿Cómo puede ayudar un array organizado a la participación ciudadana?

Respuesta:Un array organizado transforma datos sueltos
 en información accionable. Permite que la participación ciudadana
  pase de ser una intención a ser un sistema donde cada voz cuenta y
   cada acción es visible para todos.
